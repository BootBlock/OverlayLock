# Contributing to OverlayLock

Thank you for wanting to help make OverlayLock better.

## Pull requests

We're grateful for every pull request, but we're not actively accepting them at the moment, so a
pull request may be closed without being merged.

## Issues

The best way to help is to [open a new issue](https://github.com/BootBlock/OverlayLock/issues/new).
Use an issue for:

- a bug report: include the OverlayLock version (the first line of `overlay-lock --help`), the
  Windows version, the command line you used and the steps that show the problem;
- a feature request: describe what you want to do and why the current options don't let you;
- a fix or an improvement you have in mind: describe the change, and we'll take it from there.

Please search the [existing issues](https://github.com/BootBlock/OverlayLock/issues) first, in
case someone has already reported the same thing.

## Security

Don't report a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md) instead.
